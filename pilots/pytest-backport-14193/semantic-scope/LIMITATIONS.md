# Limitations

## What This Experiment Supports

- Current ARC did not distinguish compliant from behaviorally violating
  same-file patches in this controlled pytest assignment.
- File allowlists and passing command receipts were insufficient to detect the
  12 frozen violations.
- The result reproduced across three runs.
- Current path/evidence pilots should not be presented as semantic-scope
  enforcement.

## What It Does Not Support

- The scenarios were synthetic, not naturally generated by coding agents.
- The benchmark covers one pytest assignment.
- The behavioral contract was reconstructed by the experiment operator.
- The experiment does not prove which semantic-verification design will work.
- It does not measure reviewer time, review quality, production incident
  prevention, usability, adoption, pricing, or willingness to pay.
- It does not prove ARC has no value; it falsifies one stronger capability
  claim for the current engine.

## Synthetic Scenario Risk

Some violations are intentionally adversarial and include sample-specific or
unrelated behavior that normal contributors may not write. They are useful for
testing whether ARC enforces the contract, but they cannot estimate the
frequency of these failures in production.

## Test Baseline Risk

Passing the focused command does not mean a patch would pass pytest's entire CI
matrix. The experiment tests incremental value beyond the frozen focused
baseline, not merge safety.

## Reconstruction Risk

Pytest maintainers did not approve this behavioral contract. Invariants and
non-goals labeled `operator_inferred` are reasonable interpretations, not
historical maintainer decisions.

## Next Validation

After designing a reusable semantic contract primitive:

1. score it against this unchanged benchmark;
2. freeze rules before revealing labels;
3. test on a second repository;
4. then run real coding-agent assignments;
5. separately measure reviewer utility and adoption.
